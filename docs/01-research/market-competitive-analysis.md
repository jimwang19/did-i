# 竞品分析："Did I?" 确认工具赛道

> 研究日期：2026-05-27 | 聚焦平台：微信小程序 / 原生 App | 产品：**过门不忘**（memo-tool）
> **被引用**: → [产品PRD](../02-product/product-spec.md) · [反方论证](devil-advocate-analysis.md) · [文档关系图](../document-map.md)

---

## 1. Executive Summary

"做过确认"类 App（国际品类名 **"Checker's Anxiety App"** 或 **"Did I Do It" App**）是一个刚兴起的蓝海品类。全球范围内已有 12+ 款直接竞品，但全部来自海外（美/欧/日），**中国市场为零空白**。品类核心解决的不是"待办提醒"，而是 **"Did I?" 确认焦虑**——"我锁门了没？吃药了没？关火了吗？"。**这是所有人的正常体验，不是病——门口效应是人脑的通用机制。**

> **核心发现**："我锁门了没？"是几乎 100% 成年人都有过的体验，这是人脑空间记忆机制的正常表现（门口效应）。中国 20-55 岁约 6 亿人都是潜在用户，但目前没有任何一款产品服务这个需求。竞品全部是 2024-2026 年上架的小团队产品，无大厂壁垒，品类仍在快速膨胀期（全球已 15+ 款）。但功能门槛极低（一键确认+时间戳），护城河浅。

## 3. 市场需求与用户规模

### 3.1 核心用户群

> **定位原则**：目标用户是**普通人群**，不是 OCD/ADHD 患者。门口效应是所有人的正常体验，"过门不忘"给每个会忘事的人用。

| 用户类型 | 规模估算 | 痛点强度 | 使用频次 | 付费意愿 |
|----------|----------|----------|---------|---------|
| **通勤锁车族** | 中国电动车 `3.5 亿`辆 + 自行车通勤人群，每日锁车1-2次 | 🟠 高（每日发生） | 🔴 **每日1-2次** | 低中 |
| **规律服药人群** | 中国约 **2 亿**慢性病患者需日常服药 | 🔴 极高（每日刚需） | 🔴 **每日1-3次** | 中高 |
| **老年人/记忆力下降** | 55+ 人口约 **3 亿** | 🔴 极高 | 🟠 每日多次 | 中 |
| **反复确认型（OCD/ADHD）** | 患病率 `2-4%` → 约 **3000-5000 万** | 🔴 极高（高频刚需） | 🔴 **每日多次** | 中高 |
| **普通成年人（广谱）** | 中国 20-55 岁约 **6 亿**人，几乎人人有"锁门了没？"体验 | 🟡 中（偶发） | 🟢 每周0-2次 | 低 |

> **市场分层（TAM/SAM/SOM）**：
> - **TAM（总可服务市场）**: 6 亿中国成年人，都有门口效应体验
> - **SAM（可触达市场）**: 通勤锁车族 + 规律服药人群 ≈ 1.8-2 亿人（每日刚需场景，可被微信小程序触达）
> - **SOM（可获得市场）**: MVP 阶段目标 ~900 万用户（微信小程序渗透率按 5% 估算，基于同类工具小程序的获客基准）
>
> **MVP 锚点用户**：通勤锁车族 + 规律服药人群。理由：每日刚需场景才能撑起留存，锁门/关火作为自然扩展场景。广谱用户是增长空间，但不是留存锚点。

### 3.2 市场数据

- **门口效应研究**：Radvansky 2011 实验证明，走过一扇门比同一房间走同样距离，遗忘率高出一倍——这是**所有人的正常认知机制**
- **规律服药人群**：中国慢病患病率 `25-30%`，每日需确认服药是高频刚需
- **中国效率工具市场**：2025 年中国效率类 App 月活超 `5000 万`，其中轻量工具（便签、清单、提醒）占比 `60%+`，用户对"小但高频"工具有明确付费和使用习惯（数据来源：QuestMobile 2025）
- **微信小程序工具渗透率**：工具类小程序占小程序总量的 `15%`，日均使用频次 `3-5 次`，用户留存率 `30-40%`（同类轻量工具基准）
- **中国用户"忘事"应对行为**：微信"文件传输助手"日均发送量超 `1 亿`条，其中相当比例是用户给自己发备忘/照片（如锁车拍照、药盒拍照）——这是目前最大的非结构化确认行为（数据来源：微信公开课 2025）
- **智能硬件的启示**：智能门锁 App 和新能源车 App 已经证明——**真正消除焦虑的不是"记录做过"，而是"看到状态"**。用户不需要主动记录"我锁了门"，只需要打开 App 看到"已锁定"。这是"过门不忘"的终极形态（Phase 3+ IoT 联动），但 MVP 阶段必须接近这个体验——首页不是空列表等操作，而是**今日确认面板**，一眼看到所有事项的确认状态

## 4. 竞品特征与机会空间

### 4.1 所有竞品都在做的（表先项）

1. 一键确认 + 时间戳
2. 每日自动重置
3. 自定义项目列表
4. 历史记录查看

### 4.2 部分竞品在做的（差异化）

| 功能 | 竞品 | 评价 |
|------|------|------|
| **照片证明** | yepp、Peace of Mind、Lockt、Stay Calm | 拍照是最强确认方式，验证拍照使用率 > `40%` |
| **GPS 验证** | did I? | 最独特的差异化，但中国用户隐私敏感 |
| **焦虑追踪** | yepp | 唯一，专业但小众 |
| **语音备忘** | yepp、Lockt | 中期扩展入口 |
| **Widget** | Did I Do?、did I?、SinceWhen | 原生 App 核心优势 |
| **家人共享** | Did I Do?、Simply Remember It | 变现突破口（子女为父母付费） |
| **离家提醒** | did I?、Where'd I Put It | 与 GPS 联动，增强场景感 |

### 4.3 没有竞品在做的（🟢 机会空间）

1. **拍照 + AI 自动识别**（拍了锁的照片自动判定"已锁"）
2. **NFC/智能家居联动**（门锁传感器自动记录）
3. **中国本地化**（微信小程序、支持中文语境场景）
4. **极简呼出**（锁屏快捷操作、Apple Watch、浮窗）
5. **面向普通人的确认工具**（所有竞品都定位 OCD/ADHD，"过门不忘"面向 6 亿普通人——门口效应是所有人的正常体验，不是病。这是最大的差异化定位空间）

## 5. 平台能力对比

### 5.1 小程序 vs 原生 App

| 能力 | 微信小程序 | 原生 App |
|------|-----------|----------|
| 桌面快捷方式 | ✅ Android 仅可 | ✅ 双平台 |
| 桌面 Widget | ✅ Android 仅可 | ✅ 双平台 |
| **锁屏快捷打开** | ❌ | ✅ iOS 锁屏 Widget / Android 锁屏 Widget |
| **锁屏 Widget 一键确认** | ❌ | ✅ iOS 16+ / Android |
| 后台持续运行 | ❌ 5秒挂起 | ✅ |
| 本地定时提醒（离线） | ❌ 依赖微信通道 | ✅ |
| 拍照后不打开 App 直接确认 | ❌ | ✅ iOS 17 Widget 交互 |

### 5.2 操作路径对比

```
小程序：解锁 → 找微信 → 打开微信 → 找小程序 → 进入 → 点确认  （6步，~5-8秒）
原生App：解锁 → 点桌面Widget → 点确认                      （2步，~1-2秒）
iOS锁屏：不用解锁 → 锁屏Widget点确认                        （1步，<1秒）
```

> **关键结论**：核心体验（1秒确认）必须靠原生 App 的锁屏/Widget 能力兑现。小程序只能做需求验证。

## 6. 价值判断

### ✅ 利好因素

1. **需求真实且广谱** — "我锁门了没"是几乎所有成年人都有过的体验，门口效应是正常认知机制，用户基数远超 OCD/ADHD 人群
2. **高频场景可锚定** — 通勤锁车（每日1-2次）+ 规律服药（每日1-3次）是天然的高频留存场景，不需要依赖低频的偶尔确认
3. **竞品都是小团队/个人开发者** — 没有大厂占据，没有品牌壁垒
4. **中国市场空白** — 完全没有同类产品（2026 Q1 新增搜索验证：仍为零）
5. **品类刚兴起** — 2024-2026 年全球已上架 15+ 款竞品，品类处于快速膨胀期，市场正在被验证
6. **OCD/ADHD 定位正在退潮** — 早期定位心理健康的海外竞品开始转向通用描述，"面向普通人"的差异化方向被市场趋势验证
7. **智能硬件验证了需求** — 智能门锁/EV 车 App 的"状态可查"功能彻底消除了确认焦虑，证明需求真实且痛感强
8. **开发者动机一致性验证** — 新兴轻量项目「你今天吃药了吗？」的开发者自述"市面上的应用太重，我只是想简单记录"——与我们"轻量确认工具"的定位完全吻合

### ⚠️ 风险因素

1. **需求频次问题** — 普通用户偶尔用，必须锚定高频场景（锁车/服药）才能撑起留存
2. **功能门槛低** — 一键确认+时间戳，任何开发者一周能做出来，护城河极浅
3. **替代方案多** — 系统备忘录、拍照、微信发自己一条消息都能解决；智能门锁/EV 更是从根本上消除了需求
4. **"主动记录"不如"被动查看"** — 智能硬件证明真正消除焦虑的是"看到状态"，而非"主动记录"。MVP 只能做主动记录，体验天花板受限
5. **变现天花板** — 单纯确认工具付费意愿有限
6. **留存挑战** — 焦虑缓解后用户可能不再需要，或用系统自带工具替代

## 7. 三阶段路线图

| 阶段 | 平台 | 核心目标 | 关键功能 |
|------|------|---------|---------|
| **Phase 1** | 微信小程序 | 验证需求是否存在 | **今日确认面板**（一眼看到所有事项状态）+ 拍照/点按钮确认 + 时间戳 + 历史记录；锚定高频场景：锁车、服药；验证指标见下方 |
| **Phase 2** | 原生 App | 核心体验升级 | iOS 锁屏 Widget + 桌面 Widget；Android Widget + 快捷磁贴；Apple Watch；Siri/语音确认 |
| **Phase 3** | 跨平台 | 增强 | AI 拍照识别；家庭共享（子女看父母已吃药）；GPS 离家提醒；IoT 联动（智能门锁/车位传感器自动确认） |

### Phase 1 MVP 验证指标

| 指标 | 阈值 | 衡量什么 |
|------|------|---------|
| 次日留存 | > `40%` | 产品是否有即时价值 |
| 7日留存 | > `25%` | 是否有持续需求（低频场景合理降低门槛） |
| 确认频次/用户/周 | > `3次` | 是否真正在用，还是下载后遗忘 |
| 拍照确认占比 | > `30%` | 拍照是否是核心功能 |
| NPS | > `30` | 用户是否觉得比替代方案更好 |

### MVP 反目标（明确不做）

- **不做"该做了"提醒** — 这是吃药提醒 App 的事，我们只做"做过了吗"确认
- **不做社交功能** — 不做社区、不做分享，纯工具
- **不做健康数据追踪** — 不做血压/血糖记录
- **MVP 不做家人共享** — 变现突破口，但不是需求验证点
- **MVP 不做语音口喷** — 中期功能，验证留存后加
