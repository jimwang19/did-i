# 市场竞品分析报告

> 产出日期：2026-05-27
> 产品代号：做过确认（memo-tool）
> 分析范围：全球"Did I?"确认类 App + 中国相关市场

## 一、产品定位定义

核心不是"待办提醒"，而是 **"Did I?" 确认工具**——解决"我刚才到底锁门没有/吃药没有？"这类反复确认的焦虑。国际品类名：**"Checker's Anxiety App"** 或 **"Did I Do It" App**。

| 应用 | 平台 | 核心功能 | 定价 | 特色 |

### 中国市场竞品

| 应用 | 定位 | 差异 |

| 吃药啦/吃药了吗 | 纯吃药提醒 | 无"确认做过"概念 |

### 间接竞品/替代方案

| 类型 | 示例 | 劣势 |
|------|------|------|
| 系统备忘录 | iOS Notes、Google Keep | 无时间戳确认、无快捷呼出 |
| 吃药提醒 | Medisafe、PillProof | 只管"该吃了"，不管"吃过了没" |
| 习惯追踪 | Streaks、Habitica | 强调连续性，给压力，非安心 |
| 拍照发自己 | 微信文件传输 | 操作步骤多，无结构化记录 |

## 三、市场需求与用户规模

### 核心用户群

| 用户类型 | 全球规模 | 痛点强度 | 付费意愿 |
|----------|----------|----------|----------|
| OCD 检查型 | 终身患病率 2-4%，检查型占 25-40% → 约 3000-5000 万人 | 极高 | 中 |
| ADHD 患者 | 全球约 3.6 亿成人 | 高 | 中高 |
| 老年人/认知退化 | 55+ 人口数十亿 | 中高 | 低 |
| 普通焦虑人群 | 13.6% 有亚临床强迫症状 | 中 | 低 |
| 服药人群 | 仅美国 49% 成人规律服药 | 中 | 中高 |

### 市场数据

- **ADHD App 市场**：2025 年 $22-28 亿，CAGR 12-16%，亚太增速最快
- **OCD 治疗市场**：2023 年 $11 亿，CAGR 5-8%
- **焦虑类 App 渗透率**：仅 12% 焦虑症患者使用 App 管理症状，空间巨大
- **OCD 诊断率极低**：75-80% 的 OCD 患者未被诊断，存在大量隐性需求

## 四、竞品共性特征与差异点

### 所有竞品都在做的（表先项）
1. 一键确认 + 时间戳
2. 每日自动重置
3. 自定义项目列表
4. 历史记录查看

### 部分竞品在做的（差异化）
1. **照片证明** — yepp、Peace of Mind、Lockt、Stay Calm
2. **GPS 验证** — did I?（最独特）
3. **焦虑追踪** — yepp（唯一）
4. **语音备忘** — yepp、Lockt
5. **Widget** — Did I Do?、did I?、SinceWhen
6. **家人共享** — Did I Do?、Simply Remember It
7. **离家提醒** — did I?、Where'd I Put It

### 没有竞品在做的（机会空间）
1. **拍照 + AI 自动识别**（拍了锁的照片自动判定"已锁"）
2. **NFC/智能家居联动**（门锁传感器自动记录）
3. **中国本地化**（微信小程序、支持中文语境场景）
4. **极简呼出**（锁屏快捷操作、Apple Watch、浮窗）

## 五、价值判断

### 利好因素

1. **需求真实且强痛** — "我锁门了没"是几乎所有人都有过的体验
2. **竞品都是小团队/个人开发者** — 没有大厂占据，没有品牌壁垒
3. **中国市场空白** — 完全没有同类产品
4. **品类刚兴起** — 竞品基本都是 2025-2026 年上架
5. **ADHD/OCD App 市场高速增长** — CAGR 12-16%
6. **用户付费意愿存在** — 多数竞品有订阅模式，$1.99-9.99/月

### 风险因素

1. **需求频次问题** — 普通用户偶尔用，只有 OCD/ADHD 用户才是日活
2. **功能门槛低** — 一键确认+时间戳，任何开发者一周能做出来
3. **替代方案多** — 系统备忘录、拍照、微信发自己一条消息都能解决
4. **变现天花板** — 单纯确认工具付费意愿有限
5. **心理健康敏感** — 涉及 OCD/ADHD 定位需谨慎
6. **留存挑战** — 焦虑缓解后用户可能不再需要

## 六、平台能力分析

### 小程序 vs 原生 App 系统能力

| 能力 | 微信小程序 | 原生 App |
|------|-----------|----------|
| 桌面快捷方式 | ✅ Android 仅可 | ✅ 双平台 |
| 桌面 Widget | ✅ Android 仅可 | ✅ 双平台 |
| **锁屏快捷打开** | ❌ | ✅ iOS 锁屏 Widget / Android 锁屏 Widget |
| **锁屏 Widget 一键确认** | ❌ | ✅ iOS 16+ / Android |
| 后台持续运行 | ❌ 5秒挂起 | ✅ |
| 本地定时提醒(离线) | ❌ 依赖微信通道 | ✅ |
| 拍照后不打开App直接确认 | ❌ | ✅ iOS 17 Widget 交互 |

### 操作路径对比

```
小程序：解锁 → 找微信 → 打开微信 → 找小程序 → 进入 → 点确认  （6步，~5-8秒）
原生App：解锁 → 点桌面Widget → 点确认                      （2步，~1-2秒）
iOS锁屏：不用解锁 → 锁屏Widget点确认                        （1步，<1秒）
```

## 七、分阶段建议

### Phase 1 — 微信小程序 MVP（验证需求）
- 最简功能：拍照/点按钮 → 记时间戳 → 列表查看
- 利用微信社交传播，低成本获客
- 验证指标：7日留存率 > 30% 则需求成立

### Phase 2 — 原生 App（核心体验升级）
- iOS：锁屏 Widget + 桌面 Widget，一键确认
- Android：桌面 Widget + 锁屏 Widget + 快捷磁贴
- Apple Watch 支持
- Siri/语音确认

### Phase 3 — 增强
- AI 拍照识别
- 家庭共享
- GPS 离家提醒
