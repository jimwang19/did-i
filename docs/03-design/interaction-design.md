## 一、核心交互原则

1. **确认面板优先** — 打开即看到状态，不是空列表等操作
2. **最少步骤** — 确认一件事不超过 2 步操作
3. **状态视觉强于动作** — 强调"✅已确认"而非"去确认"按钮
4. **零门槛启动** — 无需登录，首次打开即可使用

## 二、页面结构

### P1：今日确认面板（首页）

**用途**: 核心页面，用户打开小程序直接看到

**布局**:
```
┌─────────────────────────┐
│  顶部栏：今日 + 日期     │
├─────────────────────────┤
│                         │
│  ✅ 锁车   08:32 拍照   │  ← 已确认项，绿色状态
│  ⏳ 服药   ─── ── ──    │  ← 待确认项，灰色状态
│  ✅ 关火   07:15 按钮   │
│  ⏳ 喂猫   ─── ── ──    │
│                         │
│  ＋ 添加事项             │
├─────────────────────────┤
│  📋 历史  │  ⚙️ 设置    │  ← 底部导航
└─────────────────────────┘
```

**交互规则**:
- 点击待确认项 → 选中高亮（蓝色边框），底部固定操作栏激活，显示「拍照确认 · 事项名」和「快速确认 · 事项名」
- 再次点击已选中的待确认项 → 取消选中，底部操作栏恢复 disabled 状态
- 点击已确认项 → 直接打开确认详情 bottom sheet（时间、方式、照片、可撤销）
- **待确认项始终排在上方，已确认项在下方**（已确认项按确认时间倒序排列）
- 点击右上角「编辑」→ 切换编辑模式，事项左侧显示删除按钮

### P2：确认操作栏（固定底部）

**用途**: 对已选中的待确认事项执行确认，无需弹出额外页面

**触发**: 点击待确认事项选中后，底部操作栏从 disabled 变为激活

**布局**:
```
┌─────────────────────────┐
│  ...事项列表...          │
│                         │
│  ▶ 锁车 #2  已选中       │  ← 蓝色高亮
│                         │
├─────────────────────────┤
│  选中「锁车」→ 底部按钮确认 │  ← 提示文字
├─────────────────────────┤
│  📷拍照确认「锁车」 ✓快速确认「锁车」│
└─────────────────────────┘
```

**交互规则**:
- 拍照确认：调用相机 → 拍照 → 自动保存 → 事项变为 ✅，移至列表下方
- 快速确认：点击即完成 → 事项变为 ✅，check 按钮有弹出动画，事项移至列表下方
- 确认完成后自动取消选中状态，底部按钮恢复 disabled
- 底部按钮文字动态显示事项名，明确操作对象（避免误确认）

### P3：添加/编辑事项

**用途**: 创建新事项或编辑已有事项

**布局**:
```
┌─────────────────────────┐
│  ← 添加事项              │
│                         │
│  事项名称                │
│  ┌─────────────────┐    │
│  │ 关火             │    │
│  └─────────────────┘    │
│                         │
│  选择图标                │
│  🔒 🚲 💊 🔥 🐱 🐶      │
│  🚪 💡 📦 ➕             │
│                         │
│  ┌─────────────────┐    │
│  │     保存          │    │
│  └─────────────────┘    │
└─────────────────────────┘
```

**交互规则**:
- 名称：必填，最多 10 个字符
- 图标：可选，从预设库选择，默认为文字首字
- 保存后自动出现在首页确认面板

### P4：历史记录

**用途**: 回看过去每天的确认情况

**布局**:
```
┌─────────────────────────┐
│  ← 历史记录    筛选 ▼    │
├─────────────────────────┤
│  📅 今天 5/27            │
│  ✅ 锁车 08:32  📷      │
│  ✅ 服药 12:15  按钮    │
│                         │
│  📅 昨天 5/26            │
│  ✅ 锁车 08:45  按钮    │
│  ✅ 服药 12:00  📷      │
│  ✅ 服药 20:30  按钮    │
│                         │
│  📅 5/25                 │
│  ✅ 锁车 09:01  📷      │
│  ⏳ 服药 （未确认）      │
└─────────────────────────┘
┘
```

**交互规则**:
- 按日期倒序排列，每天为一组
- 点击照片缩略图 → 查看大图
- 筛选：按事项筛选
- 未确认的事项显示"未确认"标记

### P5：设置

**用途**: 应用设置

**内容**:
- 每日重置时间（默认 00:00）
- 确认方式默认偏好（拍照/按钮）
- 清除数据
- 关于

## 三、导航结构

```
首页(确认面板) ← 核心入口
    ├── 点击事项 → 确认操作面板
    ├── 添加事项 → 添加/编辑事项
    ├── 长按事项 → 编辑/删除
    │
    ├── 历史(tab) → 历史记录
    └── 设置(tab) → 设置页
```

底部导航 2 个 tab：首页、历史。设置从首页右上角进入。

## 四、关键交互细节

### 4.1 每日重置

- 每日 00:00 所有事项重置为"待确认"
- 用户打开时看到全新的确认面板
- 昨日已确认的记录自动归入历史

### 4.2 确认反馈

- 确认完成：事项卡片即时变为 ✅ 状态 + 显示时间
- 短暂的 ✅ 动画（0.3s），不阻断操作
- 拍照确认：照片缩略图显示在事项卡片上

### 4.3 首次使用引导

- 首次打开自动创建"锁车"和"服药"两个预设事项
- 简短提示："点击待确认的事项，标记你已完成"
- 不做多步引导，1 句话 + 让用户直接操作

### 4.4 空状态处理

- 无事项时：显示"添加第一个确认事项"引导 + 预设模板
- 全部已确认时：显示"今日全部确认 ✅"鼓励状态

## 五、异常与边界

| 场景 | 处理 |
|------|------|
| 小程序被微信销毁后重新打开 | 本地数据持久化，恢复上次状态 |
| 照片存储空间不足 | 提示清理，不阻断按钮确认 |
| 同一事项同日多次确认 | 保留最近一次，历史记录中标注覆盖 |
| 事项超过 10 个 | 提示免费版上限，引导精简或等待付费版 |
