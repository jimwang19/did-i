# 小程序自动化测试脚本

## 概述

本目录包含微信小程序自动化测试脚本，用于验证"过门不忘"小程序的核心功能。

## 文件说明

### `test-automation.js`
- **功能**：完整的自动化测试脚本
- **测试内容**：
  - 页面标题验证
  - 底部操作区验证
  - 卡片渲染验证
  - 添加事项按钮验证
  - 筛选按钮验证
  - 控制台输出验证
  - 页面异常监测
  - 页面截图

### `enable-auto.bat`
- **功能**：启动微信开发者工具自动化服务
- **命令格式**：自动配置项目路径和端口

### `wechat-cli.bat`
- **功能**：微信开发者工具 CLI 命令包装器
- **用途**：简化 CLI 命令调用

### `test-miniprogram.js`
- **功能**：基础测试脚本（已被更新为 `test-automation.js`）

## 运行测试

### 前提条件

1. **安装依赖**：
   ```bash
   npm install miniprogram-automator
   ```

2. **开启微信开发者工具服务端口**：
   - 打开微信开发者工具
   - 点击「设置」→「安全设置」
   - 开启「服务端口」

### 运行步骤

1. **启动自动化服务**：
   ```bash
   cmd /c "D:\jim\aiwork\memo-tool\scripts\enable-auto.bat"
   ```

2. **运行测试脚本**：
   ```bash
   node D:\jim\aiwork\memo-tool\scripts\test-automation.js
   ```

### 测试结果

- **输出目录**：`test-outputs/`
- **截图文件**：`index-page.png`（页面加载后的截图）
- **控制台输出**：详细的验证结果

## 技术说明

- 使用 `miniprogram-automator` 0.12.0+ 版本
- 采用 `connect()` 方式连接到已运行的微信开发者工具
- 支持自定义组件内部元素查询
- 测试结果包含详细的断言信息和截图

## 注意事项

1. **自动化服务端口**：默认使用 9420 端口
2. **HTTP 服务端口**：默认使用 10089 端口
3. **项目路径**：测试脚本会自动查找 `.claude/worktrees/feat+mvp-miniprogram` 目录
4. **首次运行**：可能需要在微信开发者工具中确认信任项目

## 排障建议

- **连接失败**：检查服务端口是否开启，或重启微信开发者工具
- **超时**：增加超时时间（默认 60秒）
- **元素未找到**：检查选择器是否正确，或等待时间是否足够
